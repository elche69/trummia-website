# Quality Checklist

Before considering a website change complete:

- Check the page at mobile widths from 320px to 768px.
- Check the page at tablet widths from 768px to 1024px.
- Check the page at desktop widths above 1024px.
- Confirm navigation, smooth scrolling, sticky header behavior, mobile menu, and scroll animation.
- Verify every internal link points to an existing section.
- Verify every external link uses the intended destination and opens safely.
- Verify every image path resolves and every important image has appropriate alt text.
- Check for horizontal overflow, clipped text, overlap, broken wrapping, and inconsistent spacing.
- Run a whitespace or syntax check appropriate to the edited files.
- Review the final diff for unrelated changes.
- If deployment is involved, confirm the hosted URL separately from the GitHub push.
