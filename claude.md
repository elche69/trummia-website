# Trùm Mía Website Rules

The website guidance is organized as Claude Code rules under `.claude/rules/`.

- `01-brand-design.md`: brand direction, colors, typography, and visual treatment.
- `02-page-structure-content.md`: page order, section responsibilities, and content principles.
- `03-implementation.md`: static HTML/CSS/JS implementation and required interactions.
- `04-responsive-accessibility.md`: responsive breakpoints, mobile behavior, and accessibility.
- `05-seo-assets.md`: metadata, deployable assets, image handling, and verified store facts.
- `06-deployment.md`: static hosting, GitHub source, VibeZ deployment, and publishing discipline.
- `07-quality-checklist.md`: final responsive, link, asset, validation, and deployment checks.

Claude Code automatically loads project rules from `.claude/rules/`. Keep new guidance in the most specific topic file and avoid duplicating instructions here.
